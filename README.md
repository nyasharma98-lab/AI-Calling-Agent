# AI Calling Agent 

An AI-powered voice interaction system built with Python and Google Gemini API. It simulates inbound and outbound calls, understands voice input, generates intelligent responses, and manages call records.

✨ Features

- AI-powered conversations using Gemini API
- Speech-to-Text with Faster-Whisper
- Text-to-Speech with pyttsx3
- Inbound and outbound call simulation
- Customer and call management
- Call analytics and data visualization
- SQLite database and CSV reports
- REST API using FastAPI

🛠️ Tech Stack

Python • Gemini API • FastAPI • SQLite • Faster-Whisper • NumPy • Pandas • Matplotlib
